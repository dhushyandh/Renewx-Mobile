# RenewX Design System

## Brand colours
- Midnight Navy: `#111827`
- RenewX Yellow: `#FFC400`
- White: `#FFFFFF`
- Cloud Grey: `#F3F4F6`

## Supporting tokens
- Border: `#E5E7EB`
- Muted text: `#6B7280`
- Success: `#15803D`
- Error: `#DC2626`

## Principles
- Premium minimalism; product photography is the visual focus.
- Strong hierarchy and legible typography.
- 8-point spacing rhythm.
- Subtle borders and restrained shadows.
- Avoid excessive blur, gradients and glass effects.
- Accessible contrast and touch targets.
- Responsive web layout without a separate web application.

## Assets
Use local optimized assets for logos, categories, banners and illustrations. Product listings must render actual backend image URLs; do not ship fake products as content.
