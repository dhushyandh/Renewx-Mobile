# RenewX Design System

Brand palette: navy #111827, yellow #FFC400, white #FFFFFF, cloud #F3F4F6, border #E5E7EB, muted #6B7280.

Use clean retail layouts, strong typography, generous spacing, clear product photography, restrained borders and subtle shadows. Avoid heavy blur, noisy gradients and unnecessary decoration.

Mobile navigation: Home, Shop, raised Sell action, Orders, Profile. Desktop web adapts to a desktop header/navigation and wider catalogue grid. Product cards must use real product imagery, API-backed price, condition and title. Include accessible labels, focus/pressed states and sufficient contrast.
